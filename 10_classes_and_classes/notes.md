While JavaScript is fundamentally a prototype-based language, the class keyword provides a more familiar syntax for developers coming from class-based object-oriented programming languages like Java or Python.
JavaScript classes are primarily "syntactic sugar" over the existing prototype-based inheritance mechanism. They do not introduce a new object model but rather offer a cleaner and more structured way to define constructor functions and their associated methods.
